# 防犯カメラ映像 解析ツール

防犯カメラの録画を読み込み、**いつ・何が・どのくらい映っていたか**を自動でまとめます。
長い録画を全部見なくても、何か映っていた場面だけを確認できます。

## できること

| 機能 | 内容 |
|---|---|
| 検出・追跡 | 人・自転車・車・バイク・バス・トラック・犬・猫を YOLO11 で検出し、同じ対象には同じ番号を付けて追跡 |
| イベント一覧 | 1 秒以上映ったものを 1 件として、開始・終了時刻と映っていた秒数を `events.csv` に出力（Excel で開けます） |
| スナップショット | イベントごとに一番はっきり写ったコマの切り抜き画像を保存 |
| ダイジェスト動画 | 何か映っていた場面（前後 2 秒付き）だけをつなぎ、枠と時刻を入れた `digest.mp4` を作成 |
| 侵入・うろつき | 指定した監視エリア（敷地・玄関前など）に入った対象と、指定秒数以上とどまった対象を検出 |
| 通過カウント | 指定した線（入口・門など）を通った人数・台数を方向別に集計 |
| レポート | 上記をまとめた `report.html`（ブラウザで開く）。種類で絞り込みもできます |

動きのない時間帯は背景差分で検出を省くので、長時間の録画でもふつうのパソコン（GPU なし）で解析できます。

## 準備（初回だけ）

Python 3.10 以上が必要です。

```bash
cd cctv_analyzer
pip install -r requirements.txt
```

初回実行時に YOLO のモデル（約 5MB）が自動でダウンロードされます。

## 使い方

```bash
# 1 本の動画
python analyze.py 録画.mp4

# フォルダ内の動画をまとめて（サブフォルダも含む）
python analyze.py D:\camera\20261110\ --out 結果

# 録画開始時刻を指定（レポートに実際の時刻が出ます）
python analyze.py cam1.mp4 --start "2026-11-10 22:00:00"
```

Windows なら、動画ファイルやフォルダを `analyze_dragdrop.bat` にドラッグ＆ドロップするだけでも解析できます（結果は `cctv_results` フォルダに保存されます）。

ファイル名に `20261110_220000` や `2026-11-10_22-00-00` のような日時が入っていれば、録画開始時刻は自動で読み取ります。

### 監視エリア・通過ラインを使う

座標は画面に対する割合（左上が `0,0`、右下が `1,1`）で指定します。
一度ふつうに実行すると、10% 刻みの目盛りを入れた `layout.jpg` が保存されるので、それを見て座標を決めてください。

```bash
# 画面下半分の中央を監視エリアにして、20 秒以上いたら「うろつき」
python analyze.py cam1.mp4 --roi "0.3,0.5;0.7,0.5;0.7,1;0.3,1" --loiter 20

# 画面の縦 60% の高さに横線を引いて、通過を数える（上→下 / 下→上）
python analyze.py cam1.mp4 --line "0,0.6;1,0.6"
```

エリアに入ったかどうかは対象の**足元**（枠の下端の中央）で判定します。

### よく使う調整

| オプション | 既定 | 使いどころ |
|---|---|---|
| `--classes person,car` | 人・車など 8 種 | 調べたい種類だけに絞る（`person` 人、`car` 車、`bicycle` 自転車、`motorcycle` バイク、`truck` トラック、`dog` 犬、`cat` 猫 など） |
| `--conf 0.35` | 0.35 | 誤検出が多いなら上げる（0.5 など）、見逃しが多いなら下げる（0.25 など） |
| `--model yolo11s.pt` | `yolo11n.pt` | 精度を上げたいとき（`s` → `m` の順に遅く・正確になります） |
| `--imgsz 1280` | 640 | 遠くの小さな人まで拾いたいとき（遅くなります） |
| `--fps 5` | 5 | 1 秒あたり何コマ解析するか。速く終わらせたいなら 2〜3、速い動きを逃したくないなら 10 |
| `--min-duration 1` | 1 秒 | 一瞬のノイズを除く。木の揺れや虫で誤検出が多いなら 2〜3 に |
| `--motion 0.003` | 0.3% | 動き検知の敏感さ。雨や木の揺れで検出が無駄に走るなら上げる |
| `--no-motion-gate` | — | 動き検知で省かず全コマ検出する（止まっている人も確実に拾う。遅い） |
| `--no-digest` | — | ダイジェスト動画を作らない（速くなる） |

全オプションは `python analyze.py -h` で確認できます。

## 出力されるもの

```
cctv_results/
├── index.html          … 複数の動画を解析したときの一覧
├── events_all.csv      … 全動画のイベントをまとめた表
└── <動画名>/
    ├── report.html     … レポート（ブラウザで開く）
    ├── events.csv      … イベント一覧（Excel で開ける）
    ├── digest.mp4      … 何か映っていた場面だけのダイジェスト
    ├── snapshots/      … イベントごとの切り抜き画像
    ├── layout.jpg      … エリア・ラインの位置確認用（10% 目盛り付き）
    └── summary.json    … 集計結果（プログラムから使う用）
```

## 注意

- 自動検出なので、見逃しや誤検出はありえます。重要な場面は必ず元の録画で確認してください。
- 同じ人が物陰に隠れてまた出てくると、別のイベントとして数えられることがあります。人数・台数は目安です。
- 夜間の赤外線映像（白黒）でも動きますが、暗い・遠い・小さい対象は精度が落ちます。`--model yolo11s.pt --imgsz 1280` を試してください。
- このツールは「何が映っていたか」を調べるもので、顔から個人を特定する機能はありません。映像には第三者が映るため、取り扱いには注意してください。
- `.dav` など防犯カメラ独自形式で開けない場合は、レコーダー付属のソフトで MP4 に書き出すか、`ffmpeg -i 入力.dav -c copy 出力.mp4` で変換してから解析してください。
